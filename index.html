❓ How do I find my transaction hash?
  1. Send 1 DOGE to the machine address (shown above).
  2. Open your wallet, find the outgoing transaction, and copy its transaction ID / hash (64 hex characters).
  3. Paste it above and pull the lever. The machine verifies it on-chain, then dispenses.
  4. Same tx hash = same gumball, forever — keep it as your receipt ticket. One payment = one gumball.
Fairness: the prize is a pure function of your tx hash — no server secrets, no rigging. Every receipt can be replayed: python3 scripts/verify_fairness.py outputs/receipts.jsonl.
