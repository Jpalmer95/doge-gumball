How do I find my transaction hash?
  1. Send 1 DOGE to the machine address above — scan the QR from a phone wallet.
  2. Wait for 1 confirmation. Usually a minute or two.
  3. Open the transaction in your wallet and copy its transaction ID / hash (64 hex characters).
  4. Paste it above and turn the crank. Same hash = same gumball, forever. One payment = one gumball.
  5. Overpayment is a donation — the machine never sends change.
